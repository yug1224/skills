# 描画内容と出力テンプレート

## 描画内容の書き方

プレーンテキストで書く（`##`・markdown 表・入れ子 fence は使わない）。全体で 1500〜2500 字、全文日本語。短い技術識別子（`staleTime` 等）は結論の図・表の中だけで使ってよい。

```text
タイトル: 「{1 行タイトル}」

【背景・課題】
リード: 「{現状 → 何が問題かを 40〜80 字で}」
- 図解: {描く絵の説明}。キャプション「{名詞+説明文、50〜100 字}」

【結論】
リード: 「{結論の主旨を 40〜80 字で}」
■ {小見出し}
- 図解: {描く絵の説明}。キャプション「{名詞+説明文}」
- 表: {行と列の内容}
- フロー: {A → B → C}
- コールアウト「{強調したい短文}」

【今後】
- 図解: {描く絵の説明}。キャプション「{名詞+説明文}」

熊の吹き出し「{20 字前後のひとこと。技術テーマにちなんだユーモア可}」
```

- 画像に描く文言（タイトル・リード・キャプション・コールアウト・熊のセリフ）は「」で囲む
- 結論には小見出し（`■`）を 1 つ以上、表かフローを 1 つ以上、コールアウトを 1 つ以上入れる。それ以外の配分は内容に合わせる
- 漢字は JIS 第一水準・第二水準（JIS X 0208）のものだけを使う。範囲外の漢字（`髙` `﨑` `鷗` 等）は常用の字体に置き換えるか、ひらがなで書く
- ファイルパス全文・diff 行・認証情報・個人情報・社内 URL は書かない

## 出力テンプレート

`{レイアウト指示}` `{描画内容}` `{解像度}` 以外は変えない。今後が空のときは【レイアウト】の今後に関する文を削る。

```text
【出力指示】
16:9の画像を1枚だけ生成してください。テキストでの説明は不要です。画像のみ出力してください。

【レイアウト】
16:9横長（{解像度}）。画面上部にタイトル。
本文は「背景・課題」「結論」「今後」の3まとまり。「結論」の面積を最も大きくする。
配置: {レイアウト指示}
各まとまりに見出し・図解・日本語キャプションを置く。画像内の漢字はJIS第一水準・第二水準の字体だけで、【描画内容】の文字どおりに書く。図解の形・細部の配置・余白の取り方は自由に工夫してよい。
熊を1体だけ、どのまとまりとも重ならない位置に置き、吹き出しを1つ付ける。

【描画内容】
{描画内容}

【避ける要素】
判読できない小さな文字, 誤った日本語, 文字化け, JIS第一水準・第二水準にない漢字や異体字, 英語だけのキャプション, 単語だけが散らばったテキスト, 縦書きの見出し, 熊以外のマスコット, 複数の熊, まとまりに重なる熊
```
