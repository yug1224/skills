ブログ記事を `blog-review-rule` の 7 観点で採点し、`review-report-rule` の出力テンプレートで報告する。

**Input**: 記事のファイルパスまたは URL（URL は本文を取得して読む）。

## Steps

1. `~/.claude/skills/shared-rules/references/blog/blog-review-rule.md` と `~/.claude/skills/shared-rules/references/conventions/review-report-rule.md` を Read する
2. 想定読者と記事の目的を決め、7 観点で採点する
3. 減点の原因になった箇所を「重要度」に従って指摘の下書きにし、`review-report-rule` の「反証」を通す
4. 出力テンプレートで提示する。判定のラベルは ✅ 公開してよい / ⚠️ 改善の余地あり / ❌ 公開前に直す。「対象 / スコープ」に下の「スコア表」を置く

## 重要度

| Priority | 意味                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| **P0**   | 観点 6 のチェック項目に当たる表現・事実誤り・誤った実践指針・公開してはいけない情報 |
| **P1**   | 根拠のない断言（観点 1）・論理の飛躍（観点 2）・手順が欠けて再現できない（観点 3）  |
| **P2**   | 読みやすさ・伝え方・人間らしさ（観点 4・5・7）の改善                                |

場所は見出しと該当文の短い引用で示す。直し方には Before / After の書き換え例を添える。

## スコア表

```markdown
- 想定読者: {推定ならその旨} / 記事の目的: {…} / 読めた範囲: {全文 / 確認できなかった部分}
- 総合評価: X.X/5.0（観点 1〜5 の平均）/ 炎上リスク: X.X/5.0 / 人間らしさ: X.X/5.0

| 観点 | 点数 | 根拠の要点 |
| ---- | ---- | ---------- |
```
