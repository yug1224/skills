# ビルトイン PR テンプレート（プロジェクトテンプレが無いときだけ Read）

プロジェクトに PR テンプレートが無い場合のみ使用。DRESS CODE の 4 リポジトリ（backend / frontend / ui / graph-to-code）と同じ骨格にしている。

## セクションごとの変更ルール

- `## 📝 PR概要 📝` / `### 主な実装内容`: 内容変更を推奨。リポジトリ固有の項目（API 契約、影響範囲など）は `**変更点の概要**` の後に足してよい
- `## 👮‍♂️ 動作確認 👮‍♂️`: `ローカルで動作確認済み` は残す。変更に応じた確認項目は足してよい
- `## ✅ 困ったらこの辺をチェック ✅`: プロジェクトの規約文書へのリンクを置く。見つからなければ節ごと消す

## テンプレート

```markdown
## 📝 PR概要 📝

- **目的**:
  - 機能追加
  - 仕様変更
  - バグ修正
  - リファクタリング
- **関連リンク**:
  - [todo](todo)
- **変更点の概要**:
  - todo

### 主な実装内容

1. **タスク概要**
   - タスク詳細

## 👮‍♂️ 動作確認 👮‍♂️

- [ ] ローカルで動作確認済み

## ✅ 困ったらこの辺をチェック ✅

- [規約文書](https://github.com/<org>/<repo>/blob/<default-branch>/<path>)
```

## フロントエンド向け差分

**目的**に `UIスタイリングの更新` を追加し、`### 主な実装内容` の直後にスクリーンショット表を挿入する。

```markdown
### 変更前後のスクリーンショット

| before                    | after                     |
| ------------------------- | ------------------------- |
| <img src="" width="480"/> | <img src="" width="480"/> |
```
